# План и результаты тестирования

ЛР №4, вариант 16, уровни 1 и 2. Инструмент — pytest, целевое покрытие — 70%. Проект создан отдельно по варианту; оценки — целые числа 2–5. Проверяются все три модуля и их взаимодействие.

## План
1. Эквивалентное разбиение входных оценок: корректные 2–5; целые меньше 2; целые больше 5; значения других типов (включая bool).
2. Проверка ветвей добавления, удаления, вычисления среднего и итоговой успешности.
3. Интеграционные сценарии: добавление, удаление, пересчёт статистики, отклонение некорректных оценок.
4. Запуск тестов, исправление дефектов, повторное тестирование с покрытием ветвей.

## Белый ящик

Покрытие решений: обе ветви добавления, удаления и среднего. Покрытие условий: проверка типа и диапазона, наличие оценок, среднее >= 4 и отсутствие двоек получают оба логических значения в соответствующих сценариях. При коротком замыкании Python не вычисляет часть условий, когда результат уже известен.

Комбинаторное покрытие для выражения `A and (B or C)` функции is_successful: A — непустой журнал, B — среднее >= 4, C — нет двоек. Все достижимые сочетания значений переменных проверены.

| Данные | A | B | C | Результат |
|---|---|---|---|---|
| [] | 0 | 0 | 1 | 0 |
| [2] | 1 | 0 | 0 | 0 |
| [3] | 1 | 0 | 1 | 1 |
| [2,5,5] | 1 | 1 | 0 | 1 |
| [4,5] | 1 | 1 | 1 | 1 |

При A=0 среднее равно нулю и двоек нет, поэтому оставшиеся три комбинации недостижимы. Это не означает 100% MC/DC для всей системы; метрика pytest-cov измеряет строки и ветви, а не все комбинации булевых выражений.

## Баг-репорты

### BUG-01. Принимается оценка 6
Описание: верхняя граница ошибочно задана как 6. Шаги: вызвать is_valid_grade(6); создать GradeBook и вызвать add(6). Ожидалось: False и ValueError. Фактически: True, добавление разрешено. Тяжесть: средняя; приоритет: высокий. Исправление: верхняя граница 5. Статус: исправлено, повторные тесты пройдены.

### BUG-02. Удаление отсутствующей оценки без сообщения
Описание: remove() завершался без исключения. Шаги: создать пустой GradeBook, вызвать remove(5). Ожидалось: ValueError. Фактически: обычное завершение. Тяжесть: низкая; приоритет: средний. Исправление: выбрасывать ValueError. Статус: исправлено, повторный тест пройден.
