# Инспекция кода

Инструмент: flake8. Команда: `python -m flake8 src/ tests/ --max-line-length=100 --statistics --count`.

Выполнена ручная проверка структуры и читаемости: модули разделены по назначению, имена функций в snake_case, отступы в четыре пробела, ошибки входных данных обрабатываются через ValueError. Автоматическая инспекция flake8 пока не подтверждена: инструмент отсутствует в среде, где выполнялись pytest и coverage, а установка там недоступна.

## Результат локального запуска

Заполнить после выполнения команды на Windows: количество замечаний, их коды, исправления (при наличии) и результат повторного запуска. Не считать проверку завершённой до фактического запуска flake8.
